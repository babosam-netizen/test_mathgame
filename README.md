# 🏫 배곧초등학교 수학 줄다리기 대결 게임 (Baegot Math Tug-of-War Game)

초등학교 학생들이 사칙연산(덧셈, 뺄셈, 곱셈, 나눗셈, 혼합 계산)을 재미있고 흥미진진하게 학습할 수 있도록 제작된 웹 기반 **수학 줄다리기 대결 게임**입니다.

## ✨ 주요 기능
- **사칙연산 마스터**: 덧셈, 뺄셈, 곱셈, 나눗셈 및 혼합 계산 문제를 풀며 연산 실력을 키울 수 있습니다.
- **줄다리기 대결 시스템**: 양쪽 3개씩 총 6개의 소세지 마디로 이루어진 로프가 정답을 맞히거나 틀릴 때마다 한 칸씩 확실하게 움직입니다.
- **게임 설명 모달**: 게임 시작 전 규칙과 방법을 쉽고 명확하게 안내합니다.
- **스코어보드(순위표)**: 게임 종료 후 점수와 닉네임을 기록하고 확인할 수 있습니다.
- **반응형 웹 UI**: PC와 모바일 환경 모두에서 쾌적하게 즐길 수 있습니다.

## 🚀 플레이 방법
1. 게임 시작 전 안내 화면에서 규칙을 확인하고 **[게임 시작하기]** 버튼을 누릅니다.
2. 화면에 출제되는 사칙연산 문제의 정답을 입력하거나 선택합니다.
3. 정답을 맞히면 상대방 쪽으로 소세지 마디가 1칸 끌려오고, 틀리면 우리 쪽으로 1칸 끌려갑니다.
4. 소세지 줄을 모두 끌고 와서 승리하거나, 게임 종료 후 나의 기록을 스코어보드에서 확인해보세요!
