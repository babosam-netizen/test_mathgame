🐾 배곧초등학교 수학 줄다리기 대결 게임 (Baegot Math Tug-of-War Game)

초등학교 자연수의 사칙연산(덧셈, 뺄셈, 곱셈, 나눗셈 및 혼합 계산)을 재미있게 학습할 수 있는 인터랙티브 웹 기반 줄다리기 게임입니다!

✨ 주요 기능 및 특징

자연수 사칙연산 학습: 덧셈, 뺄셈, 곱셈, 나눗셈, 괄호가 포함된 혼합 계산 문제 출제

인터랙티브 소세지 줄다리기 애니메이션: 정답을 맞히면 햄스터(플레이어)가 소세지 줄을 마디별로 당기고, 틀리면 컴퓨터(COM) 쪽으로 밀려나는 6마디 세그먼트 로프 시각 효과

스코어보드 (명예의 전당): 게임 종료 후 닉네임을 입력하고 최고 점수 TOP 5를 기록 및 저장

몰입감을 높이는 UI/UX: 시작 전 규칙 안내 모달, 반응형 디자인, 오프스크린 결과 오버레이 제공

🚀 플레이 방법

저장소에 있는 baegot_math_game.html 파일을 브라우저로 엽니다.

시작 화면에서 규칙을 읽고 '게임 시작하기' 버튼을 누릅니다.

화면에 나오는 수학 문제를 풀고 4개의 보기 중 정답을 선택합니다.

소세지 6마디를 상대방 쪽으로 모두 끌고 오면 승리합니다!
